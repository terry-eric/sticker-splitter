# sticker-splitter

# ✂️ 貼圖切割工具 (純網頁版)

這是一款完全在瀏覽器端運行的貼圖與精靈圖 (Sprite Sheet) 切割與處理工具。
**無須安裝任何軟體、無須後端伺服器，圖片完全不會上傳到雲端**，100% 保障您的隱私與資料安全。

專為 **LINE 貼圖創作者** 與 **遊戲開發者 (2D Sprite)** 設計，提供智慧去背、自動框選、自動加白邊、LINE 貼圖規格最佳化以及一鍵 ZIP 打包下載等強大功能。

---

## ✨ 核心特色

- 🔒 **純前端執行**：基於 HTML5 Canvas 與純 JavaScript 打造，無任何伺服器依賴，雙擊 `index.html` 即可離線使用。
- 🪄 **智慧去背與魔術棒**：
  - **邊緣自動去白底**：支援 8 方位擴展偵測，自動消除複雜的純色或漸層背景（支援自訂去背嚴格度）。
  - **魔術棒工具**：滑鼠點擊即可智慧消除封閉的背景區塊（如角色手臂腋下的背景）。
- 📦 **強大的框選系統**：
  - **自動偵測 (BFS)**：自動辨識並框選獨立的圖像區塊。
  - **棋盤格切割**：支援「指定欄列數」或「指定固定長寬」，遊戲精靈圖切割超方便。
  - **精細微調**：支援手動拖曳新增、移動、縮放框線；也可一鍵將所有框強制設為「統一尺寸並置中對齊」。
- 🎨 **專業貼圖輸出**：
  - **高品質實心白邊**：利用圓周偏移疊加演算法（Dilation），產生平滑無破洞的完美描邊。
  - **LINE 貼圖最佳化**：自動將長寬進位至「雙數 (偶數)」，並支援設定最大長寬（例如 370x320），自動高畫質等比例縮放，保證上架不被退件。
  - **一鍵打包 ZIP**：整合 `JSZip`，一鍵將所有切好的貼圖打包成 ZIP 檔下載。

## 🚀 快速開始

1. 將專案下載到本地端。
2. 確保你的網路有連線（因為系統需要透過 CDN 載入 Tailwind CSS 與 JSZip 函式庫）。
3. 直接用瀏覽器（建議使用 Google Chrome 或 Edge）雙擊打開 `index.html`。
4. 點擊左上角的 **「選擇圖片」** 開始使用！

## 🛠️ 功能操作說明

### 1. 檔案與底圖處理
- **啟用智慧邊緣去白底**：若上傳的圖片帶有白色底圖，打勾即可自動去除。若上傳的圖片本身已是去背透明圖（或帶有半透明煙霧特效），請**取消勾選**以免破壞半透明特效。
- **去背嚴格度**：遇到假透明棋盤格或去背不乾淨時，將數值**調低**；若發現角色白色的部分被誤刪，請將數值**調高**。

### 2. 產生與重置框線
- **過濾最小面積**：用來消除畫面上的細微雜訊粉塵，面積小於此設定的紅框會被自動過濾。
- **合併鄰近框距離**：若角色的配件（如汗水、愛心）被切成不同區塊，可調高此數值讓它們自動合併。若角色之間靠太近被誤認成同一個，請設為 `0`。
- *(註：調整滑桿後，請點擊「🔧 僅過濾 / 整理目前的框」才會套用)*
- **強制統一尺寸**：抓取畫面上最大的框，或手動輸入長寬，將所有貼圖強制統一尺寸並置中對齊，非常適合處理 Sprite 動畫。

### 3. 工具列 (畫布區)
- **🔲 調整框線**：在畫布上直接拖曳框的四個角落進行縮放，或點擊空白處拉出新的框。
- **🪄 魔術棒去背**：點選畫面上沒去乾淨的底色，系統會自動將其透明化。

### 4. 輸出樣式
- **透明邊距 (Padding)**：圖案與邊界之間的留白距離。
- **白邊寬度**：實心輪廓線的厚度。
- **LINE 貼圖優化**：打勾後，系統會自動幫您檢查導出的長寬是否為雙數，並可設定最高解析度上限（預設 370x320），超過會自動進行高品質縮放。
